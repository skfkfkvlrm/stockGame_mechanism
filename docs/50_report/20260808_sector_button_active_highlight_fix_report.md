# 분야 및 정렬 필터 활성화 선택 스타일 강조 조치 보고서

## 1. 개요
공유해주신 사용자 화면 캡처에서 밝은 배경(Light Theme) 환경으로 인해 분야 필터 버튼(`sector-btn`)의 선택 상태(`active`) 배경색과 글자색이 투명하게 가려져 선택 여부가 보이지 않던 스타일 현상을 조치했습니다.

---

## 2. 주요 조치 내역 (`StockList.css`)

1. **미선택 상태(기본/호버) 시인성 강화**:
   - `background`: `#f3f4f6` (밝은 회색)
   - `border`: `1px solid #d1d5db`
   - `color`: `#4b5563` (시독성 높은 진한 회색)

2. **선택 상태(`active`) 명확한 하이라이트 색상 부여**:
   - `background`: `#4f46e5 !important` (선명한 딥 바이올렛/블루)
   - `color`: `#ffffff !important` (선명한 흰색 텍스트)
   - `border`: `#4338ca !important`
   - `box-shadow`: `0 4px 12px rgba(79, 70, 229, 0.4)` 그림자 효과 부여

---
