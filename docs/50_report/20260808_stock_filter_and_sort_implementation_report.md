# 주식 목록 필터링 및 정렬 기능 구현 보고서

## 1. 개요
주식 목록 페이지(`StockList.jsx`)에 사용자 요구사항인 **분야 필터**, **오름차순 (가격 낮은순)**, **내림차순 (가격 높은순)**, **거래량 (발행량)순** 등 총 4가지 정렬/필터링 기능을 추가 구현했습니다.

---

## 2. 주요 구현 내역

1. **분야별 필터링 (8개 필터 태그 지원)**:
   - `전체`, `간식/매점`, `학교생활/쿠폰`, `게임/여가`, `엔터/미디어`, `문구/학용품`, `스포츠/취미`, `미래기술/IT` 버튼 제공.
   - 특정 분야 버튼 클릭 시 해당 분야에 등록된 주식 종목만 필터링되어 목록에 즉시 반환됩니다.

2. **3가지 정렬 옵션 구현**:
   - **오름차순 (`ASC`)**: 주식 현재가가 낮은 순서대로 정렬.
   - **내림차순 (`DESC`)**: 주식 현재가가 높은 순서대로 정렬.
   - **거래량 (`VOLUME`)**: 주식 발행량(거래량)이 많은 순서대로 정렬.

3. **종목 카드 및 테이블 UI 개선 (`StockList.jsx`, `StockList.css`)**:
   - 종목별 분야 정보를 한눈에 확인할 수 있도록 배지(`sector-badge`) 디자인 추가.
   - 필터링 결과가 없을 경우 사용자에게 명확하게 빈 결과 안내 문구 표시.
