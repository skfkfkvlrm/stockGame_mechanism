# 분야 다중(중복) 선택 및 자동 전체 선택 기능 구현 보고서

## 1. 개요
기존에 단일 분야만 선택이 가능하던 분야 필터를 **중복 선택(다중 선택)이 가능하도록 개편**하고, **7개 전체 분야가 모두 선택되거나 아무것도 선택되지 않은 경우 자동으로 '전체' 버튼으로 수렴**하도록 조치했습니다.

---

## 2. 주요 구현 내역 (`StockList.jsx`)

1. **상태 구조 개편 (`selectedSectors` 배열 사용)**:
   - 기존 단일 문자열 `selectedSector`에서 선택된 분야들의 배열 `selectedSectors` (`['전체']`, `['간식/매점', '엔터/미디어']` 등) 상태로 변경.

2. **다중 선택 & 수렴 클릭 핸들러 (`handleSectorClick`)**:
   - **'전체' 버튼 클릭 시**: 다른 선택 분야를 모두 해제하고 `['전체']` 상태로 초기화.
   - **'전체'가 선택된 상태에서 개별 분야 클릭 시**: '전체'가 자동 해제되고 클릭한 개별 분야만 새로 선택.
   - **개별 분야 개별 토글**: 클릭할 때마다 해당 분야의 선택/해제를 자유롭게 전환.
   - **자동 전체 수렴 규칙**:
     - 선택을 모두 해제하여 0개가 된 경우 -> 자동으로 `['전체']` 선택.
     - **7개 분야('간식/매점', '학교생활/쿠폰', '게임/여가', '엔터/미디어', '문구/학용품', '스포츠/취미', '미래기술/IT')가 모두 선택된 경우 -> 자동으로 '전체' 버튼 하나만 활성화 수렴**.

3. **다중 선택 필터링 로직**:
   - `selectedSectors`에 `'전체'`가 없는 경우, 선택된 분야 배열 내에 포함된 주식 종목만 필터링하여 노출.
