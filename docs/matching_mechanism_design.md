# 📈 학급 환경(20~30명) 최적화 stockGame 체결 메커니즘 설계서

## 1. 핵심 해결 과제 (학급 환경의 한계)
* **극심한 호가 공백 (Market Freezing)**: 참여자가 적어 매수-매도 희망가 간격(Spread)이 벌어지면 며칠 동안 거래가 단 한 건도 체결되지 않음.
* **소수 담합에 의한 시세 조종 (어뷰징/자전거래)**: 2~3명의 학생이 비우량주를 1주씩 주고받으며 가격을 왜곡하거나 봇을 타깃으로 포인트를 부당 복사할 위험.
* **비현실적인 급등락**: 완충 장치가 없어 한 번의 이상 주문으로 시세가 비정상적으로 요동침.

## 2. 3대 체결 메커니즘

### ① 실제 거래소를 재현한 'Static VI (정적 변동성 완화장치)'
* **발동 조건**: 직전 단일가 결정 가격(또는 당일 기준가 ef_price) 대비 체결 예정 가격이 **±10% 이상 급등락**할 경우 즉시 발동.
* **동작 방식**: 
  * 정규 접속매매(연속체결)를 일시 중단하고 **2분간(수업 템포에 맞춰 1~2분) 단일가 매매(Call Auction)**로 강제 전환.
  * 2분 동안 들어오는 주문은 즉시 체결하지 않고 오더북에 누적.
  * 제한 시간 종료 시, **'최대 거래량을 발생시키는 단 하나의 합치가격'**을 산출하여 일괄 체결 처리 후 새로운 ef_price로 갱신하고 접속매매 재개.
* **교육 효과**: 시장 이상 과열 시 냉각기를 주는 실제 한국거래소의 시장 안정화 메커니즘을 체험.

### ② '체결 중개'와 '어뷰징 차단'에 한정된 '패시브 LP 봇 (Passive Bridge Bot)'
* **상시 개입 금지**: 봇이 평소에 호가를 깔아두면 학생들의 '포인트 복사기'가 되므로, 오더북 매수/매도 스프레드가 **일정 기준(예: 5%) 이상 벌어져 거래가 끊겼을 때만 조건부 개입**.
* **어뷰징 방지 스마트 기준가 (VWAP)**:
  * 봇이 호가를 제시하는 기준 가격은 직전 1건의 왜곡된 체결가가 아니라, **'최근 N건의 거래량 가중 평균가(VWAP)'**를 사용.
  * 소수 학생이 1주씩 가격을 띄우는 자전거래로는 봇의 기준가를 조작할 수 없음.
* **수학적 무위험 차익 차단 (Spread Margin)**:
  * 봇의 매수 호가와 매도 호가 사이에 항상 일정한 마진(예: 기준가 대비 매수 950원 / 매도 1,050원)을 두어, 봇을 상대로 즉각 사고파는 단타를 칠 경우 무조건 손실이 나도록 설계.
* **탐지 회피 난수 (Randomness)**: 봇의 개입 타이밍과 주문 수량에 미세한 랜덤성을 부여하여 학생들이 봇의 패턴을 기계적으로 예측하지 못하게 방어.

### ③ T+0 즉시 반영 vs T+2 결제 연출 (하이브리드 결제)
* **백엔드**: 빠른 피드백과 게임성을 위해 체결 즉시 포인트/주식 원장에 반영(T+0).
* **프론트엔드 UI**: 매도 대금을 'T+2 결제 대기 자금(출금 제한 포인트)'으로 묶어두는 시각적 연출을 주어, 실제 증권 시장의 결제 주기 개념을 자연스럽게 학습.

## 3. 체결 내역(Trade History) 화면 표시 방안
1. **체결 유형(Trade Type) 뱃지 추가**:
   * **일반 체결 (P2P)** (블루): 학생 간 정상 1:1 매칭.
   * **⚡ 정적 VI** (앰버): 10% 이상 튀어 2분 단일가 합치가격으로 일괄 체결된 건.
   * **🤖 LP 중개** (퍼플): 호가 단절 시 SYSTEM_LP 봇이 중개해 준 건.
2. **정적 VI 이벤트 구분선 (Divider)**: VI 발동 시점과 해제 시점을 테이블 중간에 시각적 안내선으로 표시하여 주문 집합 및 단일가 체결 과정을 체감.
3. **관리자용 자전거래 의심 태그**: 동일 인물이 짧은 시간 내 가격을 띄우며 거래를 주고받을 경우 관리자 화면에 이상 징후([🚨 자전거래 의심])를 하이라이트.
