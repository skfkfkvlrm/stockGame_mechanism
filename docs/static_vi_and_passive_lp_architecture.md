# ⚙️ Static VI(정적 변동성 완화장치) 및 Passive LP 봇 상세 아키텍처 설계서

> 본 문서는 학급 환경(20~30명)의 한계를 극복하고 실제 거래소의 시장 안정화 및 유동성 공급 메커니즘을 완벽하게 재현하기 위한 **Static VI(정적 변동성 완화장치)** 및 **Passive Bridge LP 봇**의 상세 기술 스펙과 백엔드 전산 흐름을 정리한 설계서입니다.

---

## 1. 실제와 동일한 'Static VI (정적 변동성 완화장치)' 재현 설계

실제 한국거래소의 정적 VI는 당일 누적된 주가의 비정상적인 괴리를 통제하기 위해 **'직전 단일가매매 결정 가격'**을 기준 삼아 **$\pm 10\%$** 변동 시 발동하며, 즉시 **2분간 단일가매매**로 강제 전환합니다.

stockGame 백엔드(stock-service)에 이를 구현하기 위한 구체적인 스펙입니다:

* **기준 참조가격 (ef_price) 정립**:
  * 각 종목 테이블(Stock)에 ef_price 컬럼을 추가합니다. 이 가격은 **자정의 스케줄러 기준가** 또는 **가장 최근에 정적 VI가 해제되면서 결정된 단일가(합치가격)**로 동적으로 갱신됩니다.
* **발동 조건 실시간 감시**:
  * StockOrderServiceImpl 매칭 엔진 내에서 주문이 체결되기 직전, 체결 예정 가격이 ef_price 대비 **$\pm 10\%$ 범위를 초과하는지 검증**하는 로직을 삽입합니다.
  * 범위를 초과할 경우, 해당 매칭 트랜잭션을 일시 정지(Lock)하고 해당 종목의 상태(market_status)를 CONTINUOUS(접속매매)에서 **STATIC_VI** 상태로 실시간 전환합니다.
* **단일가 매매(Call Auction) 모드 가동**:
  * **전산적 처리**: 정적 VI가 발동된 2분(수업 시간 템포에 맞춰 1분~2분 조절 가능) 동안은 들어오는 매수/매도 호가를 실시간으로 즉시 매칭하지 않고, 단순히 오더북(큐)에 적재만 합니다.
  * **화면 연출 (React)**: Zustand 스토어를 통해 화면에 '정적 VI 발동! 단일가 매매 진행 중' 경고 뱃지를 띄우고, 호가창을 실시간 체결창이 아닌 **'예상 체결가 및 예상 체결량'을 보여주는 화면**으로 전환하여 긴장감을 유도합니다.
* **단일가 합치 체결 및 기준가 갱신**:
  * 제한 시간 종료 시, 누적된 주문들을 정렬하여 **'최대 거래량을 발생시키는 단 하나의 가격'**을 도출해 일괄 체결 처리합니다.
  * 이 결정된 체결가를 새로운 ef_price로 갱신한 뒤, 시장 상태를 다시 CONTINUOUS로 변경하고 실시간 접속매매를 재개합니다.

## 2. 봇의 역할 제한: '체결 중개' 및 '어뷰징 차단' (Passive Bridge Bot)

봇이 상시 호가를 깔아두면 학생들이 봇의 자금을 무한히 갈취하는 '포인트 복사' 타깃이 될 수 있습니다. 따라서 봇은 평소엔 조용히 잠들어 있다가 필요할 때만 가동되는 **'수동적 중개자(Passive Bridge)'**로 제한합니다.

* **체결 중개 (Liquidity Bridge) 발동 조건**:
  * **호가 빙하기 개입**: 오더북 최우선 매수 호가(학생 A)와 최우선 매도 호가(학생 B)의 간극(Spread)이 **기준치(예: 5%) 이상 벌어져 거래가 단절**되었을 때만 백엔드 스케줄러(MarketMakerScheduler)가 봇을 가동시킵니다.
* **스마트 기준가 (VWAP)를 통한 시세 조종 원천 차단**:
  * 학생들이 1주씩 자전거래하여 현재가를 폭등시킨 뒤 봇에게 비싸게 넘기려 할 때, 봇은 단순히 '직전 현재가'를 기준으로 삼지 않습니다.
  * 봇은 데이터베이스의 최근 체결 이력을 조회하여 **'최근 N건의 거래량 가중 평균가(VWAP)'**를 기준가격으로 산출합니다. 소수 인원의 고의적인 소량 거래로는 이 VWAP 기준가격을 왜곡시킬 수 없습니다.
* **수학적 무위험 차익거래 차단 (Spread Margin)**:
  * 봇은 언제나 **'자신이 살 가격(매수 호가) < 자신이 팔 가격(매도 호가)'의 스프레드 갭**을 확실하게 확보하여 호가를 넣습니다.
  * *예시*: VWAP 기준가가 1,000원이고 시장 스프레드가 10% 벌어져 있다면, 봇은 **[매수 호가: 950원] / [매도 호가: 1,050원]**으로 개입합니다.
  * 학생이 1,050원에 봇의 주식을 사서 다시 봇에게 950원에 즉시 팔 경우 무조건 10%의 손실이 확정되므로, 매크로나 기계적인 단타 어뷰징이 수학적으로 불가능해집니다.
* **랜덤성 가미를 통한 패턴 암기 방지**:
  * 학생들이 봇의 개입 타이밍을 예측해 주문을 선점하는 행위(Bot Hunting)를 차단하기 위해, 봇의 개입 시간 주기(예: 30초~60초 사이 랜덤), 호가 수량(예: 10주~30주 사이 랜덤)에 **미세한 난수(Randomness)를 반영**합니다.

## 3. 프로젝트의 핵심 전산 흐름 (Backend Flow)

`
[학생 주문 제출] 
       │
       ▼
[원장 잔고/예수금 검증] (Pre-Trade Check)
       │
       ▼
[매칭 엔진 진입] ─── (종목 상태가 'STATIC_VI' 인가?) ───► YES ───► [단일가 큐에 적재]
       │                                                                  │
       NO (일반 정규장 접속매매)                                              │ (제한 시간 종료)
       │                                                                  ▼
       ├─► 체결가 예측 ──► (기준가 대비 ±10% 초과?) ──► YES ──► [정적 VI 발동 (2분 단일가)]
       │                                                          (Websocket 브로드캐스트)
       │                                                                  │
       ▼ (정상 체결 범위 내)                                                ▼
   [즉시 체결] ──► [실시간 체결 DB 기록]                         [최대 거래량 단일가 일괄 체결]
                         ▲                                                │
                         │                                                ▼
              [호가 공백 5% 이상 발생 시]                         [새로운 기준가(ref_price) 갱신]
                         │
              [SYSTEM_LP 봇 개입 지정가 호가 제출]
`

## 4. 기대 교육 효과

1. **완벽한 제도 학습**: 학생들은 단순한 가격 변동을 넘어, 실제 금융 시장의 핵심 안전판인 **"정적 변동성 완화장치(VI)와 단일가 매매"**의 구동 원리를 직접 체험할 수 있습니다.
2. **건전한 투자 유도**: 봇을 상대로 한 단순 단타/포인트 복사 시도가 스프레드 마진(Spread Margin)으로 차단되어, **뉴스 분석에 기반한 건전한 가치/우량주 투자**로 자연스럽게 유도됩니다.
