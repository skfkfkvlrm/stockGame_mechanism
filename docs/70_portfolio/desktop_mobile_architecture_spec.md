# [기획서] 데스크톱(www) 및 모바일(m) 반응형 지원 레이아웃 기획서

## 1. 개요 (Overview)
본 기획서는 STKGAME 모의 주식 거래 서비스의 **데스크톱 웹 환경(www)**과 **모바일 환경(m)**을 단일 React Single Page Application(SPA) 환경에서 효율적으로 지원하기 위한 반응형 아키텍처 및 화면 레이아웃 설계 명세서입니다.

---

## 2. 도메인 및 레이아웃 처리 방안

### 2.1 멀티 도메인 지원 정책 (`www.stkgame.com` & `m.stkgame.com`)
- **라우팅 및 도메인 바인딩**: `www`와 `m` 두 도메인 모두 동일한 React SPA 번들에 연결됩니다.
- **자동 감지 및 전환**:
  - `www` 도메인 접속 시 모바일 크기(≤ 768px)인 경우 모바일 맞춤 뷰 적용.
  - `m` 도메인 접속 시 태블릿/데스크톱 크기(> 768px)인 경우 기기의 가로 폭(Viewport Width)을 감지하여 사이드바가 포함된 넓은 레이아웃으로 자동 전환.

---

## 3. 기기별 반응형 레이아웃 명세

| 디바이스 구분 | 브레이크포인트 | 네비게이션 구조 | 주식 목록 레이아웃 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **스마트폰 (Mobile)** | `width <= 640px` | 하단 고정 탭바 (Bottom Navigation) | 카드 형태 (Mobile Card View) | 터치 중심 UI |
| **태블릿 (Tablet)** | `641px <= width <= 1024px` | 슬림 좌측 사이드바 (Navigation Rail) | 테이블 형태 (밀도 조정) | 가로 공간 효율화 |
| **데스크톱 (Desktop)** | `width > 1024px` | 완전 확장 좌측 사이드바 (Sidebar) | 고정 헤더 스크롤 테이블 | 대화면 최적화 |

---

## 4. 모바일/데스크톱 핵심 UI 컴포넌트 변환 정책

1. **사이드바 <-> 하단 탭바 (Bottom Navigation)**:
   - 스마트폰 화면에서는 좌측 사이드바가 숨겨지고, 화면 하단에 [주식거래], [실시간 랭킹], [시장 뉴스], [쿠폰 상점], [마이페이지] 5개 메인 탭바가 고정 배치됩니다.

2. **주식 테이블 <-> 모바일 카드 뷰**:
   - 데스크톱에서는 8개 컬럼을 가진 스크롤 테이블로 표현되며, 모바일 환경에서는 종목별 [현재가], [등락률], [거래량], [매수 버튼]이 한눈에 들어오는 터치 친화적 카드로 직관적으로 전환됩니다.

3. **모달 (Modal) <-> 하단 시트 (Bottom Sheet)**:
   - 모바일 환경에서 계정 추가, 포인트 관리 등의 모달창은 화면 하단에서 위로 입체적으로 올라오는 BottomSheet 형태를 적용합니다.
